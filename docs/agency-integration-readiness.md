# Agency Integration Readiness Checklist

## Agency and program identification
- [ ] Confirm agency name, program, jurisdiction, award year, and eligible student population.
- [ ] Verify institutional and program eligibility directly with the agency.
- [ ] Obtain current participation, data-sharing, security, and reporting agreements.
- [ ] Confirm approved endpoints, transport method, certificates, credentials, and test environment.
- [ ] Identify agency contacts for operations, security incidents, and reconciliation.

## Technical readiness
- [ ] Complete data-flow diagram and field-level data map.
- [ ] Define request/response schemas, validation, retries, timeouts, and idempotency.
- [ ] Use approved authentication, MFA for administrators, secrets management, and certificate rotation.
- [ ] Implement sandbox testing with synthetic records only.
- [ ] Validate award status, disbursement status, reversals, returns, and duplicate prevention.
- [ ] Complete end-to-end reconciliation against the institutional ledger.

## Go-live gate
- [ ] Agency has approved production access.
- [ ] Security and privacy reviews are signed.
- [ ] Incident notification contacts and timelines are documented.
- [ ] Staff training and support procedures are complete.
- [ ] Rollback, outage, and manual-contingency procedures are tested.
- [ ] Written go-live approval is recorded by authorized officers.

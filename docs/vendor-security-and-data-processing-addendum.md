# Vendor Security and Data Processing Addendum

**Draft template — legal approval required before signature**

## Vendor obligations
- Process student and financial-aid information only for documented purposes and instructions.
- Apply appropriate administrative, technical, and physical safeguards.
- Restrict access to authorized personnel using least privilege and MFA.
- Maintain encryption, logging, vulnerability management, backups, and secure disposal.
- Notify Bonds University promptly of suspected incidents and cooperate with investigation and required reporting.
- Obtain written approval before using subcontractors or changing processing locations.
- Support student-record requests, audits, investigations, and lawful agency reviews.
- Return or securely delete data at termination, subject to mandatory retention rules.
- Provide current security documentation and participate in periodic risk reassessment.
